# Tabuada-em-Phyton
Idioma: Português
Linguagem: Phyton 3.x
Finalidade: Programa simples desenvolvido para calcular e exibir os 10 primeiros produtos do número escolhido de forma rápida e organizada.
O que o programa faz: Gerador de tabuada interativo em Phyton, que lê o número digitado pelo usuário e exibe automaticamente toda a tabuada de multiplicação correspondente (de 1 a 10) de forma organizada no terminal.
Dependências: Nenhuma biblioteca externa é necessária.
Como iniciar o programa: Extraia o arquivo ZIP e, em seguida, utilize a opção "File > Open Folder" no VS para abrir a pasta Tabuada-em-Phyton-main. Ela contém os arquivos `main.py`, `LICENSE.docx`.
Instale o Python 3 e a extensão "Python" da Microsoft para o VS Code, caso ainda não os tenha instalado. Downloads do Python: https://www.python.org/downloads/
Extensão: https://marketplace.visualstudio.com/items?itemName=ms-python.python
Abra o arquivo `main.py` e salve-o. No menu "Run" (Executar) do editor, selecione a opção "Run Python File in Terminal" (Executar arquivo Python no terminal). Se for solicitado que você escolha um interpretador, selecione a versão do Python 3 que você instalou
Uso principal: Clique no terminal aberto para o programa. Digite um número inteiro de 0 a 1000 e pressione Enter. O programa não exibe um prompt antes de aguardar a entrada de dados. Ele imprime dez linhas, com multiplicadores de 1 a 10, e depois encerra a execução. Cada linha segue o formato x * i = resultado, em que x é o valor digitado por você e i é o multiplicador. O comando utilizado para iniciar o programa e o número digitado por você não fazem parte da saída gerada pelo programa.
